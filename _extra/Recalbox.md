## Enable SSH

1. Menu → Network Name → Enable WiFi → On.
2. Network Name → `<ssid>`.
3. WiFi Password → `<password>` → Start.
4. Connect with:
   ```
   host: recalbox (or ip-address)
   port: 22
   username: root
   password: recalboxroot
   ```
