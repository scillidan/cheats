## Config

### Windows

1. Download https://buildbot.libretro.com/nightly/windows/x86_64/RetroArch_cores.7z
2. Decompress and put `*.dll` into `RetroArch\cores\`

### ARM64

```sh
git clone --depth=1 https://github.com/christianhaitian/retroarch-cores
```

Decompress `aarch64/*.zip` and put `*.so` into `~/.config/retroarch/cores/`
