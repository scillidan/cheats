## config

1. Download [wlx_fileinfo224.zip](http://fg.tcplugins.free.fr/wlx_fileinfo224.zip) from [Fileinfo](http://fg.tcplugins.free.fr/fileinfo.htm).
2. Decompress and move to `%commander_path%\plugins\wlx\fileinfo\fileinfo.wlx64\`.
3. DoubleCommander -> Configuration -> Options -> Plugins -> Viewer plugins -> Add
	- Plugin: %commander_path%\plugins\wlx\fileinfo\fileinfo.wlx64
	- Name: fileinfo
